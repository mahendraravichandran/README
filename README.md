## About

Security Operations Engineer focused on **detection engineering, threat hunting, and incident response**. I write SIEM detections, hunt across security telemetry at scale, and build Python automation that makes security operations faster and more reliable. Recently completed my M.S. in Cybersecurity Analytics & Operations at Penn State.

## What I Do

- 🔍 Author detection rules and hunt queries in **OpenSearch (Query DSL, PPL)** across multi-source telemetry
- 🎯 Map detections to **MITRE ATT&CK** techniques and tune to reduce false positives
- ⚡ Build **Python automation** for alert enrichment, triage, and threat-intel integration
- 🛡️ Investigate endpoint, network, and identity telemetry with a threat-first mindset
- ☁️ Harden **AWS** posture through least-privilege IAM and CloudTrail-based anomaly detection
